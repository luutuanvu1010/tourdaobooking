# 07 — DESIGN TOKENS (bước 7: bề mặt và hệ thị giác)

> Template rỗng, chỉ điền trong `project/`. Nguồn token duy nhất của dự án: mọi giá trị giao diện trong code phải sinh từ đây, hardcode ngoài nguồn token là vi phạm P6/N7 và bị fitness function chặn (CONTROL_GATES tầng 1). Design đề xuất, chủ dự án duyệt (vai A ở RACI).

## 3. Khoảng cách, bo góc, bóng
spacing scale, radius, shadow, mỗi thứ một bảng nhỏ.

## 4. Breakpoint
Các mốc responsive và quy tắc co giãn.

## 5. Chuyển động
Duration, easing; quy tắc tôn trọng prefers-reduced-motion.

## Quy tắc đổi token
Đổi giá trị token là cửa hai chiều (đổi nhanh, có duyệt). Đổi cấu trúc token hoặc thêm hệ màu mới là rebrand, cần chủ dự án phê chuẩn (ARTIFACT_OWNERSHIP).
