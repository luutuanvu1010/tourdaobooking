# Đăng nhập nhanh bằng Face ID (passkey): kế hoạch thi công

> **Cho AI thi công:** SUB-SKILL BẮT BUỘC: dùng superpowers:subagent-driven-development (khuyến nghị) hoặc superpowers:executing-plans để làm theo từng task. Các bước dùng hộp kiểm (`- [ ]`) để theo dõi.

**Mục tiêu:** người dùng bật passkey (Face ID/Touch ID/vân tay) cho tài khoản, rồi đăng nhập một chạm, không gõ SĐT/PIN. PIN giữ nguyên làm đường dự phòng, đúng ADR-0016 lát 0 + lát 1.

**Kiến trúc:**
- **Kiểm WebAuthn** tự viết bằng Web Crypto, thuần và có test, đặt trong module `auth`: gồm giải CBOR, `authenticatorData`, đổi khoá COSE sang SPKI, và chữ ký ES256/RS256.
- **Thách thức** nằm trong cookie tạm ký bằng khoá dẫn xuất riêng.
- **"Dùng một lần"** bằng một câu UPDATE có điều kiện trên `last_used_at`.
- **Bảng `aut_passkey`** (migration 0023) thuộc `auth`.
- **Route công khai** (đăng nhập) ở `auth`. **Route cần đăng nhập** (bật, gỡ, đặt PIN bằng Face ID, nút admin) ở `accounts`, vì module này đã được import `auth` và `audit`.
- Sau mọi cách đăng nhập vẫn cấp cookie `td_session` như cũ.

**Công nghệ:** TypeScript, Cloudflare Workers + D1, Web Crypto (`crypto.subtle`), `node --test`, esbuild. **Không** thêm dependency.

**Đặc tả:** `docs/superpowers/specs/2026-09-23-passkey-design.md`. Căn cứ trên: `docs/adr/ADR-0016-dang-nhap-nhanh-passkey-google-oidc.md` (accepted).

## Trọng tâm rà soát (lỗi dễ cắn người dùng nhất mà luồng chính không tự lộ ra)

1. **Passkey đã gỡ ở máy chủ vẫn còn trong iCloud** và vẫn hiện trong danh sách chọn. Phải trả 401 `passkey_unknown` với câu hướng dẫn đăng nhập bằng PIN, không báo lỗi chung. Test ở Task 9 (bước "gỡ rồi đăng nhập").
2. **Bật trên máy thứ hai đã đồng bộ iCloud:** trình duyệt ném `InvalidStateError` vì `excludeCredentials`, và giao diện phải báo "Máy này đã bật Face ID cho tài khoản.". Gửi lại cùng một khoá lên máy chủ thì 409 `passkey_exists`. Test ở Task 10 (`passkeyErrorMessage`) và Task 9 (409).
3. **Người dùng bấm huỷ Face ID** (`NotAllowedError`/`AbortError`): không hiện lỗi đỏ, không gọi máy chủ. Test ở Task 10 (`passkeyErrorMessage` trả `null`).
4. **Bảo trì bật:** đăng nhập passkey là route **công khai** nên không đi qua cổng bảo trì của router, route phải tự gọi `maintenanceBlock`. Test ở Task 9.
5. **Tài khoản bị ngưng giữa lúc lấy thách thức và lúc gửi xác minh:** phải bị từ chối. Test ở Task 9. Ngoài ra kiểm bất biến ở Task 12: không có passkey còn hiệu lực của tài khoản đã ngưng.

```js
// Bản thử lát 0 (ADR-0016 điều 9): passkey + chuyển hướng kiểu Google trên iPhone thật ở chế độ app cài. KHÔNG thuộc app, không đụng D1/production.
// Chạy từ gốc repo: node docs/evidence/2026-09-23-passkey/thu-iphone/server.mjs   (chủ dự án tự chạy cloudflared ở cửa sổ khác — xem HUONG-DAN.md)
import { createServer } from "node:http";
import { appendFileSync, readFileSync } from "node:fs";
import { randomBytes } from "node:crypto";

const DIR = new URL("./", import.meta.url);
const ICONS = new URL("../../../../public/icons/", import.meta.url);
const PORT = Number(process.env.PORT ?? 8799);
const OUT = new URL("ket-qua.jsonl", DIR);
const STATIC = {
  "/": ["index.html", "text/html; charset=utf-8", DIR],
  "/app.js": ["app.js", "text/javascript; charset=utf-8", DIR],
  "/manifest.webmanifest": ["manifest.webmanifest", "application/manifest+json", DIR],
  "/icon-192.png": ["icon-192.png", "image/png", ICONS],
  "/apple-touch-icon.png": ["apple-touch-icon.png", "image/png", ICONS],
};
const b64u = (buf) => Buffer.from(buf).toString("base64url");
const cookieOf = (req, name) => (req.headers.cookie ?? "").split(/;\s*/).find((c) => c.startsWith(`${name}=`))?.slice(name.length + 1) ?? null;
const record = (entry) => appendFileSync(OUT, JSON.stringify({ at: new Date().toISOString(), ...entry }) + "\n");

createServer((req, res) => {
  const url = new URL(req.url ?? "/", "http://x");
  const origin = `https://${req.headers.host}`; // cloudflared giữ nguyên Host của tên miền tạm
  const file = STATIC[url.pathname];
  if (req.method === "GET" && file) {
    res.writeHead(200, { "content-type": file[1], "cache-control": "no-store" });
    return res.end(readFileSync(new URL(file[0], file[2])));
  }
  if (req.method === "GET" && url.pathname === "/challenge") {
    res.writeHead(200, { "content-type": "application/json", "cache-control": "no-store" });
    return res.end(JSON.stringify({ challenge: b64u(randomBytes(32)) }));
  }
  if (req.method === "POST" && url.pathname === "/report") {
    let body = "";
    req.on("data", (c) => (body.length < 50_000 ? (body += c) : null));
    req.on("end", () => {
      try { record({ report: JSON.parse(body) }); } catch { record({ report: "không đọc được" }); }
      res.writeHead(204).end();
    });
    return;
  }
  // Mô phỏng Google: đặt cookie tạm, rời sang MỘT TÊN MIỀN KHÁC (httpbin.org), tên miền đó chuyển hướng 302 về lại. Không cần OAuth client thật.
  if (req.method === "GET" && url.pathname === "/bounce/start") {
    const state = b64u(randomBytes(16));
    const back = `${origin}/bounce/back?state=${state}`;
    res.writeHead(302, {
      "set-cookie": `sim=${state}; Path=/; Max-Age=600; HttpOnly; Secure; SameSite=Lax`,
      location: `https://httpbin.org/redirect-to?url=${encodeURIComponent(back)}&status_code=302`,
    });
    return res.end();
  }
  if (req.method === "GET" && url.pathname === "/bounce/back") {
    const kept = cookieOf(req, "sim") !== null && cookieOf(req, "sim") === url.searchParams.get("state");
    record({ bounce: { cookieKept: kept, ua: req.headers["user-agent"] } });
    res.writeHead(200, { "content-type": "text/html; charset=utf-8", "cache-control": "no-store" });
    return res.end(`<!doctype html><meta name="viewport" content="width=device-width, initial-scale=1"><body style="font:18px system-ui;padding:24px">
<h1>Đã quay về</h1><p>Cookie còn giữ: <b>${kept ? "CÓ" : "KHÔNG"}</b></p><p>Đang ở: <b id="m"></b></p><p><a href="/">Về trang thử</a></p>
<script>const s = navigator.standalone === true || matchMedia("(display-mode: standalone)").matches; document.getElementById("m").textContent = s ? "cửa sổ app cài" : "tab Safari / khung trình duyệt";
fetch("/report", { method: "POST", body: JSON.stringify({ action: "bounce", cookieKept: ${kept}, standalone: s }) });</script></body>`);
  }
  res.writeHead(404).end();
}).listen(PORT, () => console.log(`Bản thử passkey chạy ở http://localhost:${PORT} — mở đường hầm: cloudflared tunnel --url http://localhost:${PORT}`));
```

```js
const results = [];
const isStandalone = () => navigator.standalone === true || matchMedia("(display-mode: standalone)").matches;
const logEl = document.getElementById("log");
const log = (o) => {
  results.push({ at: new Date().toISOString(), standalone: isStandalone(), ...o });
  logEl.textContent = results.map((r) => JSON.stringify(r)).join("\n");
};
const fromB64u = (s) => Uint8Array.from(atob(s.replace(/-/g, "+").replace(/_/g, "/")), (c) => c.charCodeAt(0));
const getChallenge = async () => fromB64u((await (await fetch("/challenge")).json()).challenge);
let pre = null;
const refill = async () => { pre = await getChallenge(); };
const flagsOf = (authData) => {
  const b = new Uint8Array(authData);
  return { up: !!(b[32] & 1), uv: !!(b[32] & 4), backupEligible: !!(b[32] & 8), backedUp: !!(b[32] & 16), signCount: new DataView(b.buffer, b.byteOffset).getUint32(33) };
};

async function create(mode) {
  try {
    const challenge = mode === "fetch" ? await getChallenge() : pre;
    const cred = await navigator.credentials.create({ publicKey: {
      challenge, rp: { id: location.hostname, name: "Thử Tour Đảo" },
      user: { id: crypto.getRandomValues(new Uint8Array(16)), name: "thu-nghiem", displayName: "Thử nghiệm" },
      pubKeyCredParams: [{ type: "public-key", alg: -7 }, { type: "public-key", alg: -257 }],
      authenticatorSelection: { residentKey: "required", requireResidentKey: true, userVerification: "required" },
      attestation: "none", timeout: 120000,
    } });
    const r = cred.response;
    log({ action: "create", mode, ok: true, attachment: cred.authenticatorAttachment ?? null, hasGetPublicKey: typeof r.getPublicKey === "function",
      alg: r.getPublicKeyAlgorithm?.() ?? null, ...(r.getAuthenticatorData ? flagsOf(r.getAuthenticatorData()) : { authDataApi: false }) });
  } catch (e) { log({ action: "create", mode, ok: false, error: e.name, message: String(e.message).slice(0, 200) }); }
  finally { void refill(); }
}

async function get(mode) {
  try {
    const challenge = mode === "fetch" ? await getChallenge() : pre;
    const cred = await navigator.credentials.get({ publicKey: { challenge, rpId: location.hostname, userVerification: "required", allowCredentials: [], timeout: 120000 } });
    const r = cred.response;
    log({ action: "get", mode, ok: true, attachment: cred.authenticatorAttachment ?? null, userHandleBytes: r.userHandle ? r.userHandle.byteLength : null, ...flagsOf(r.authenticatorData) });
  } catch (e) { log({ action: "get", mode, ok: false, error: e.name, message: String(e.message).slice(0, 200) }); }
  finally { void refill(); }
}
```

```ts
import { attemptCount, attemptDeleteIdStatement, attemptDeleteKeyStatement, attemptInsertStatement, attemptPruneStatement, lockedPhoneKeys } from "./repository.ts";

const countIn = (db: D1Database, key: string, now: number) => attemptCount(db, key, cutoff(now));

export async function reserveAttempts(db: D1Database, keys: { key: string; max: number }[], now = Date.now()): Promise<Reservation> {
  for (const k of keys) {
    const { n, oldest } = await countIn(db, k.key, now);
    if (n >= k.max) return { allowed: false, retryAfterSeconds: retryAfter(oldest, now) };
  }
  const ids: Record<string, string> = {};
  const inserts = keys.map((k) => {
    ids[k.key] = crypto.randomUUID();
    return attemptInsertStatement(db, ids[k.key]!, k.key, now);
  });
  await db.batch([attemptPruneStatement(db, cutoff(now)), ...inserts]);
  for (const k of keys) {
    const { n, oldest } = await countIn(db, k.key, now);
    if (n > k.max) {
      await db.batch(Object.values(ids).map((id) => attemptDeleteIdStatement(db, id)));
      return { allowed: false, retryAfterSeconds: retryAfter(oldest, now) };
    }
  }
  return { allowed: true, ids };
}

export async function clearAttempts(db: D1Database, phoneKey: string | null, ids: Record<string, string>): Promise<void> {
  const stmts = Object.values(ids).map((id) => attemptDeleteIdStatement(db, id));
  if (phoneKey) stmts.push(attemptDeleteKeyStatement(db, phoneKey));
  if (stmts.length) await db.batch(stmts);
}

export async function lockedPhones(db: D1Database, now = Date.now()): Promise<Set<string>> {

}
```

```js
// Authenticator GIẢ cho test (đơn vị + e2e): sinh đúng định dạng WebAuthn mà iPhone/Chrome gửi, bằng Web Crypto của Node. KHÔNG dùng ở mã chạy thật.
const enc = new TextEncoder();

/** Bộ mã hoá CBOR tối thiểu (số nguyên, chuỗi, byte, mảng, map, true/false/null) — đủ cho attestationObject và khoá COSE. */
export function cborEncode(value) {
  const out = [];
  const head = (major, n) => {
    if (n < 24) out.push((major << 5) | n);
    else if (n < 0x100) out.push((major << 5) | 24, n);
    else if (n < 0x10000) out.push((major << 5) | 25, n >> 8, n & 0xff);
    else out.push((major << 5) | 26, (n >>> 24) & 0xff, (n >>> 16) & 0xff, (n >>> 8) & 0xff, n & 0xff);
  };
  const put = (v) => {
    if (typeof v === "number") {
      if (!Number.isInteger(v)) throw new Error("cborEncode: chỉ số nguyên");
      v >= 0 ? head(0, v) : head(1, -1 - v);
    } else if (typeof v === "string") { const b = enc.encode(v); head(3, b.length); out.push(...b); }
    else if (v instanceof Uint8Array) { head(2, v.length); out.push(...v); }
    else if (Array.isArray(v)) { head(4, v.length); v.forEach(put); }
    else if (v instanceof Map) { head(5, v.size); for (const [k, x] of v) { put(k); put(x); } }
    else if (v === false) out.push(0xf4);
    else if (v === true) out.push(0xf5);
    else if (v === null) out.push(0xf6);
    else throw new Error("cborEncode: kiểu không hỗ trợ");
  };
  put(value);
  return Uint8Array.from(out);
}
```

```ts
// Bộ giải CBOR (RFC 8949) TỐI THIỂU cho WebAuthn: attestationObject và khoá COSE. Thuần, không phụ thuộc.
// Chỉ nhận: số nguyên (tới 2^53), chuỗi byte, chuỗi UTF-8, mảng, map (khoá số/chuỗi, không trùng), false/true/null.
// Từ chối: độ dài không xác định, tag, số thực, simple khác, lồng quá 8 tầng, khai độ dài vượt dữ liệu có thật.
export type CborValue = number | string | boolean | null | Uint8Array | CborValue[] | Map<number | string, CborValue>;

export class CborError extends Error {}

const MAX_DEPTH = 8;

export function decodeCbor(bytes: Uint8Array, offset = 0): { value: CborValue; end: number } {
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  const utf8 = new TextDecoder("utf-8", { fatal: true });
  let pos = offset;
  const need = (n: number) => {
    if (n < 0 || pos + n > bytes.length) throw new CborError("CBOR bị cụt");
  };
  const readLength = (info: number): number => {
    if (info < 24) return info;
    if (info === 24) { need(1); return bytes[pos++]!; }
    if (info === 25) { need(2); const v = view.getUint16(pos); pos += 2; return v; }
    if (info === 26) { need(4); const v = view.getUint32(pos); pos += 4; return v; }
    if (info === 27) {
      need(8);
      const hi = view.getUint32(pos), lo = view.getUint32(pos + 4);
      pos += 8;
      if (hi > 0x1fffff) throw new CborError("Số CBOR quá lớn");
      return hi * 2 ** 32 + lo;
    }
    throw new CborError("CBOR độ dài không xác định không được hỗ trợ");
  };
  const item = (depth: number): CborValue => {
    if (depth > MAX_DEPTH) throw new CborError("CBOR lồng quá sâu");
    need(1);
    const first = bytes[pos++]!;
    const major = first >> 5, info = first & 0x1f;
    switch (major) {
      case 0: return readLength(info);
      case 1: return -1 - readLength(info);
      case 2: { const n = readLength(info); need(n); const v = bytes.slice(pos, pos + n); pos += n; return v; }
      case 3: {
        const n = readLength(info);
        need(n);
        let v: string;
        try { v = utf8.decode(bytes.subarray(pos, pos + n)); } catch { throw new CborError("UTF-8 hỏng"); }
        pos += n;
        return v;
      }
      case 4: {
        const n = readLength(info);
        need(n); // mỗi phần tử ≥ 1 byte: khai nhiều hơn số byte còn lại là giả
        const arr: CborValue[] = [];
        for (let i = 0; i < n; i++) arr.push(item(depth + 1));
        return arr;
      }
      case 5: {
        const n = readLength(info);
        need(n * 2);
        const map = new Map<number | string, CborValue>();
        for (let i = 0; i < n; i++) {
          const k = item(depth + 1);
          if (typeof k !== "number" && typeof k !== "string") throw new CborError("Khoá map CBOR phải là số hoặc chuỗi");
          if (map.has(k)) throw new CborError("Khoá map CBOR bị trùng");
          map.set(k, item(depth + 1));
        }
        return map;
      }
      case 7:
        if (info === 20) return false;
        if (info === 21) return true;
        if (info === 22) return null;
        throw new CborError("Kiểu CBOR không hỗ trợ");
      default:
        throw new CborError("Kiểu CBOR không hỗ trợ");
    }
  };
  const value = item(0);
  return { value, end: pos };
}
```

```js
  };
  return {
    id,
    async register(challenge, o = {}) {
      userHandle = o.userHandle ?? null;
      const idLen = new Uint8Array(2);
      new DataView(idLen.buffer).setUint16(0, credentialId.length);
      const attested = concat(new Uint8Array(16), idLen, credentialId, cborEncode(await cose()));
      const ad = await authData(o.flags ?? 0x45, o, attested);
      const attestationObject = cborEncode(new Map([["fmt", "none"], ["attStmt", new Map()], ["authData", ad]]));

    async sign(challenge, o = {}) {

      if (o.tamper) sig = sig.map((b, i) => (i === sig.length - 1 ? b ^ 1 : b));
      return { id, rawId: id, type: "public-key", response: { clientDataJSON: b64u(cd), authenticatorData: b64u(ad), signature: b64u(sig), userHandle } };
    },
  };
}
```

```ts
  try { u = new URL(origin); } catch { return null; }
  if (u.origin !== origin || u.hostname !== rpId) return null;
  const local = rpId === "localhost" || rpId === "127.0.0.1";
  if (u.protocol !== "https:" && !(u.protocol === "http:" && local)) return null;
  return { rpId, origin };
}

export function credentialIdOf(credential: unknown): string | null {
  if (!credential || typeof credential !== "object") return null;
  const id = (credential as Record<string, unknown>).id;
  return typeof id === "string" && id.length >= 16 && id.length <= 1400 && B64URL.test(id) ? id : null;
}

export const counterRegressed = (stored: number, next: number): boolean => stored > 0 && next > 0 && next <= stored;

function checkClientData(bytes: Uint8Array, expected: { type: "webauthn.create" | "webauthn.get"; challenge: string; origin: string }): void {
  let d: Record<string, unknown>;
  try { d = asObject(JSON.parse(new TextDecoder("utf-8", { fatal: true }).decode(bytes))); } catch { throw new WebAuthnError("bad_client_data"); }
  if (d.type !== expected.type) throw new WebAuthnError("bad_type");
  if (d.challenge !== expected.challenge) throw new WebAuthnError("bad_challenge");
  if (d.origin !== expected.origin) throw new WebAuthnError("bad_origin");
  if (d.crossOrigin === true) throw new WebAuthnError("cross_origin");
}

export function parseAuthenticatorData(bytes: Uint8Array): AuthenticatorData {
  if (bytes.length < 37) throw new WebAuthnError("bad_auth_data");
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  const flags = bytes[32]!;
  const out: AuthenticatorData = { rpIdHash: bytes.slice(0, 32), flags, signCount: view.getUint32(33) };
  let pos = 37;
  try {
    if (flags & FLAG_AT) {
      if (bytes.length < pos + 18) throw new WebAuthnError("bad_auth_data");
      const len = view.getUint16(pos + 16);
      pos += 18;
      if (len < 16 || len > 1023 || bytes.length < pos + len) throw new WebAuthnError("bad_credential_id");
      out.credentialId = bytes.slice(pos, pos + len);
      pos += len;
      const key = decodeCbor(bytes, pos);
      if (!(key.value instanceof Map)) throw new WebAuthnError("bad_public_key");
      out.publicKeyCose = key.value;
      pos = key.end;
    }
    if (flags & FLAG_ED) pos = decodeCbor(bytes, pos).end;
  } catch (e) {
    if (e instanceof WebAuthnError) throw e;
    throw new WebAuthnError("bad_auth_data");
  }
  if (pos !== bytes.length) throw new WebAuthnError("bad_auth_data");
  return out;
}

async function checkAuthData(ad: AuthenticatorData, rp: RelyingParty): Promise<void> {
  if (!timingSafeEqual(ad.rpIdHash, await sha256(enc.encode(rp.rpId)))) throw new WebAuthnError("bad_rp_id");
  if (!(ad.flags & FLAG_UP)) throw new WebAuthnError("no_user_presence");
  if (!(ad.flags & FLAG_UV)) throw new WebAuthnError("no_user_verification");
}

async function importKey(spki: Uint8Array, algorithm: number): Promise<CryptoKey> {
  try {
    if (algorithm === -7) return await crypto.subtle.importKey("spki", spki.slice(), { name: "ECDSA", namedCurve: "P-256" }, false, ["verify"]);
    if (algorithm === -257) return await crypto.subtle.importKey("spki", spki.slice(), { name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" }, false, ["verify"]);
  } catch {
    throw new WebAuthnError("bad_public_key");
  }
  throw new WebAuthnError("unsupported_algorithm");
}

async function coseToSpki(cose: Map<number | string, CborValue>): Promise<{ spki: Uint8Array; algorithm: PasskeyAlgorithm }> {
  const kty = cose.get(1), alg = cose.get(3);
  if (kty === 2 && alg === -7) {
    const crv = cose.get(-1), x = cose.get(-2), y = cose.get(-3);
    if (crv !== 1 || !(x instanceof Uint8Array) || !(y instanceof Uint8Array) || x.length !== 32 || y.length !== 32) throw new WebAuthnError("bad_public_key");
    const spki = new Uint8Array(P256_SPKI_PREFIX.length + 65);
    spki.set(P256_SPKI_PREFIX);
    spki[P256_SPKI_PREFIX.length] = 0x04;
    spki.set(x, P256_SPKI_PREFIX.length + 1);
    spki.set(y, P256_SPKI_PREFIX.length + 33);
    await importKey(spki, -7); // ném nếu điểm không nằm trên đường cong P-256
    return { spki, algorithm: -7 };
  }
  if (kty === 3 && alg === -257) {
    const n = cose.get(-1), e = cose.get(-2);
    if (!(n instanceof Uint8Array) || !(e instanceof Uint8Array) || n.length < 256 || n.length > 513 || e.length === 0 || e.length > 8) throw new WebAuthnError("bad_public_key");
    let key: CryptoKey;
    try {
      key = await crypto.subtle.importKey("jwk", { kty: "RSA", n: toBase64Url(n), e: toBase64Url(e), alg: "RS256", ext: true }, { name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" }, true, ["verify"]);
    } catch {
      throw new WebAuthnError("bad_public_key");
    }
    return { spki: new Uint8Array(await crypto.subtle.exportKey("spki", key)), algorithm: -257 };
  }
  throw new WebAuthnError("unsupported_algorithm");
}

/** Chữ ký ECDSA dạng DER (authenticator gửi) → r‖s cố định `size * 2` byte (Web Crypto đòi). */
export function derToP1363(der: Uint8Array, size = 32): Uint8Array {
  if (der.length < 8 || der[0] !== 0x30 || der[1] !== der.length - 2) throw new WebAuthnError("bad_signature");
  const out = new Uint8Array(size * 2);
  let pos = 2;
  for (let k = 0; k < 2; k++) {
    if (der[pos] !== 0x02) throw new WebAuthnError("bad_signature");
    const len = der[pos + 1]!;
    pos += 2;
    if (len < 1 || len > size + 1 || pos + len > der.length) throw new WebAuthnError("bad_signature");
    let int = der.subarray(pos, pos + len);
    pos += len;
    if (int.length === size + 1) {
      if (int[0] !== 0) throw new WebAuthnError("bad_signature");
      int = int.subarray(1);
    }
    out.set(int, k * size + (size - int.length));
  }
  if (pos !== der.length) throw new WebAuthnError("bad_signature");
  return out;
}

/** Đăng ký (navigator.credentials.create): trả khoá cần lưu. Bỏ qua fmt/attStmt (attestation "none", ADR-0016 điều 2). */
export async function verifyRegistration(rp: RelyingParty, challenge: string, credential: unknown): Promise<NewPasskey> {
  const c = asObject(credential);
  const r = asObject(c.response ?? {});
  if (c.type !== undefined && c.type !== "public-key") throw new WebAuthnError("bad_type");
  const clientData = b64(r.clientDataJSON, "bad_client_data");
  checkClientData(clientData, { type: "webauthn.create", challenge, origin: rp.origin });
  const attBytes = b64(r.attestationObject, "bad_attestation");
  let att: CborValue;
  try {
    const d = decodeCbor(attBytes);
    if (d.end !== attBytes.length) throw new WebAuthnError("bad_attestation");
    att = d.value;
  } catch {
    throw new WebAuthnError("bad_attestation");
  }
  const authData = att instanceof Map ? att.get("authData") : undefined;
  if (!(authData instanceof Uint8Array)) throw new WebAuthnError("bad_attestation");
  const ad = parseAuthenticatorData(authData);
  await checkAuthData(ad, rp);
  if (!(ad.flags & FLAG_AT) || !ad.credentialId || !ad.publicKeyCose) throw new WebAuthnError("bad_auth_data");
  const credentialId = toBase64Url(ad.credentialId);
  if (c.id !== credentialId) throw new WebAuthnError("id_mismatch");
  const { spki, algorithm } = await coseToSpki(ad.publicKeyCose);
  return { credentialId, publicKey: toBase64Url(spki), algorithm, signCount: ad.signCount };
}

/** Đăng nhập / xác nhận (navigator.credentials.get) bằng khoá đã lưu. Trả bộ đếm mới; người gọi tự kiểm `counterRegressed`. */
export async function verifyAssertion(rp: RelyingParty, challenge: string, stored: { publicKey: string; algorithm: number }, credential: unknown): Promise<{ signCount: number }> {
  const c = asObject(credential);
  const r = asObject(c.response ?? {});
  if (c.type !== undefined && c.type !== "public-key") throw new WebAuthnError("bad_type");
  const clientData = b64(r.clientDataJSON, "bad_client_data");
  checkClientData(clientData, { type: "webauthn.get", challenge, origin: rp.origin });
  const authData = b64(r.authenticatorData, "bad_auth_data");
  const ad = parseAuthenticatorData(authData);
  await checkAuthData(ad, rp);
  if (ad.flags & FLAG_AT) throw new WebAuthnError("bad_auth_data");
  const signature = b64(r.signature, "bad_signature");
  const key = await importKey(b64(stored.publicKey, "bad_public_key"), stored.algorithm);
  const data = concat(authData, await sha256(clientData));
  const ok = stored.algorithm === -7
    ? await crypto.subtle.verify({ name: "ECDSA", hash: "SHA-256" }, key, derToP1363(signature).slice(), data)
    : await crypto.subtle.verify({ name: "RSASSA-PKCS1-v1_5" }, key, signature.slice(), data);
  if (!ok) throw new WebAuthnError("bad_signature");
  return { signCount: ad.signCount };
}
```

```ts
// Thách thức WebAuthn trong cookie tạm ký HMAC (ADR-0016 điều 2, 8) — không lưu D1. THUẦN.
// Khoá ký DẪN XUẤT riêng từ SESSION_SECRET bằng nhãn mục đích, và token có 7 phần (phiên có 3): token thách thức không bao giờ qua được
// `verifySessionToken`, và ngược lại (test ở challenge.test.ts). Token: w1.<mục đích>.<staffId|->.<ms phát hành>.<challenge>.<phụ|->.<chữ ký>.
import { fromBase64Url, timingSafeEqual, toBase64Url } from "../../shared/encoding.ts";

export const CHALLENGE_COOKIE = "td_webauthn";
export const CHALLENGE_TTL_SECONDS = 300;
export type ChallengePurpose = "login" | "register" | "pin";

const KEY_LABEL = "td-webauthn-challenge-v1";
const enc = new TextEncoder();

async function hmac(key: Uint8Array, data: string): Promise<Uint8Array> {
  const k = await crypto.subtle.importKey("raw", key.slice(), { name: "HMAC", hash: "SHA-256" }, false, ["sign"]);
  return new Uint8Array(await crypto.subtle.sign("HMAC", k, enc.encode(data)));
}
const signingKey = (secret: string) => hmac(enc.encode(secret), KEY_LABEL);

export async function issueChallenge(
  secret: string,
  purpose: ChallengePurpose,
  staffId: string | null,
  extra: string | null = null,
  now = Date.now(),
  random: Uint8Array = crypto.getRandomValues(new Uint8Array(32)),
): Promise<{ token: string; challenge: string; issuedAt: number }> {
  const challenge = toBase64Url(random);
  const payload = ["w1", purpose, staffId ?? "-", String(now), challenge, extra ?? "-"].join(".");
  return { token: `${payload}.${toBase64Url(await hmac(await signingKey(secret), payload))}`, challenge, issuedAt: now };
}

export async function readChallenge(
  secret: string,
  token: string | null,
  purpose: ChallengePurpose,
  staffId: string | null,
  now = Date.now(),
): Promise<{ challenge: string; issuedAt: number; extra: string | null } | null> {
  if (!token) return null;
  const parts = token.split(".");
  if (parts.length !== 7) return null;
  const [v, p, s, iat, challenge, extra, sig] = parts as [string, string, string, string, string, string, string];
  if (v !== "w1" || p !== purpose || s !== (staffId ?? "-")) return null;
  let given: Uint8Array;
  try { given = fromBase64Url(sig); } catch { return null; }
  if (!timingSafeEqual(await hmac(await signingKey(secret), parts.slice(0, 6).join(".")), given)) return null;
  const issuedAt = Number(iat);
  if (!Number.isSafeInteger(issuedAt) || issuedAt > now + 60_000 || now >= issuedAt + CHALLENGE_TTL_SECONDS * 1000) return null;
  return { challenge, issuedAt, extra: extra === "-" ? null : extra };
}

export const challengeCookie = (token: string, secure: boolean): string =>
  `${CHALLENGE_COOKIE}=${token}; Path=/api; Max-Age=${CHALLENGE_TTL_SECONDS}; HttpOnly; SameSite=Strict${secure ? "; Secure" : ""}`;
export const clearedChallengeCookie = (secure: boolean): string =>
  `${CHALLENGE_COOKIE}=; Path=/api; Max-Age=0; HttpOnly; SameSite=Strict${secure ? "; Secure" : ""}`;
```

```ts
/** Cấu hình RP, hoặc null (TẮT). Ghi cảnh báo MỘT lần mỗi isolate để thiếu cấu hình không thành tắt lặng lẽ (như Turnstile). */

export async function limitChallenge(request: Request, env: Env): Promise<Response | null> {
  const ip = request.headers.get("cf-connecting-ip") ?? "unknown";

/**
 * Kiểm một lần xác nhận bằng passkey (đăng nhập hoặc đặt PIN): tìm khoá còn hiệu lực → (nếu `ownerId`) đúng chủ → chữ ký → bộ đếm → dùng một lần.
 * Thành công thì `last_used_at` đã được ghi (thách thức này không dùng lại được nữa).
 */
export async function checkPasskeyAssertion(
  env: Env,
  rp: RelyingParty,
  ch: { challenge: string; issuedAt: number },
  credential: unknown,
  ownerId: string | null,
): Promise<{ ok: true; passkey: PasskeyRow } | { ok: false; response: Response }> {
  const id = credentialIdOf(credential);
  if (!id) return { ok: false, response: error(400, "invalid_input", "Thiếu dữ liệu Face ID.") };
  const pk = await findActivePasskey(env.DB, id);
  if (!pk) return { ok: false, response: PASSKEY_ERRORS.unknown() };
  if (ownerId !== null && pk.staff_id !== ownerId) return { ok: false, response: PASSKEY_ERRORS.notYours() };
  let signCount: number;
  try {
    ({ signCount } = await verifyAssertion(rp, ch.challenge, { publicKey: pk.public_key, algorithm: pk.algorithm }, credential));
  } catch (e) {
    logPasskeyRejected(e);
    return { ok: false, response: PASSKEY_ERRORS.invalid() };
  }
  if (counterRegressed(pk.sign_count, signCount)) {
    logPasskeyRejected(new WebAuthnError("counter_regressed"));
    return { ok: false, response: PASSKEY_ERRORS.invalid() };
  }
  if (!(await markPasskeyUsed(env.DB, pk.id, signCount, new Date().toISOString(), new Date(ch.issuedAt).toISOString()))) return { ok: false, response: PASSKEY_ERRORS.expired() };
  return { ok: true, passkey: pk };
}
```

```js
const RP = { rpId: new URL(BASE).hostname, origin: new URL(BASE).origin };
const cookieJar = (...parts) => parts.filter(Boolean).join("; ");
const challengeCookie = (r) => {
  const all = r.headers.getSetCookie?.() ?? [r.headers.get("set-cookie") ?? ""];
  const c = all.find((x) => x.startsWith("td_webauthn=") && !x.startsWith("td_webauthn=;"));
  return c ? c.split(";")[0] : null;
};
const sessionCookie = (r) => {
  const all = r.headers.getSetCookie?.() ?? [r.headers.get("set-cookie") ?? ""];
  const c = all.find((x) => x.startsWith("td_session="));
  return c ? c.split(";")[0] : null;

async function enable(cookie, pin, auth, o = {}) {
  const opt = await call(cookie, "POST", "/api/account/passkeys/options", { pin });
  if (opt.status !== 200) return opt;
  const cred = await auth.register(opt.body.publicKey.challenge, { userHandle: opt.body.publicKey.user.id, ...o });
  return call(cookieJar(cookie, challengeCookie(opt)), "POST", "/api/account/passkeys", { credential: cred });
}
async function passkeyLogin(auth, o = {}) {
  const opt = await call(null, "POST", "/api/auth/passkey/options", {}, freshIp());
  assert.equal(opt.status, 200, JSON.stringify(opt.body));
  const cred = await auth.sign(opt.body.publicKey.challenge, o);
  const r = await call(challengeCookie(opt), "POST", "/api/auth/passkey/login", { credential: cred }, freshIp());
  return { r, replay: () => call(challengeCookie(opt), "POST", "/api/auth/passkey/login", { credential: cred }, freshIp()) };
}
```

```ts
import type { Api } from "./api";
import { fromBase64Url, toBase64Url } from "../src/shared/encoding";

const buf = (s: string): ArrayBuffer => fromBase64Url(s).slice().buffer;
const b64 = (b: ArrayBuffer | null): string | null => (b ? toBase64Url(new Uint8Array(b)) : null);

export const passkeySupported = (): boolean => typeof window.PublicKeyCredential === "function" && !!navigator.credentials;

export async function platformAuthenticatorAvailable(): Promise<boolean> {
  try {
    return passkeySupported() && (await PublicKeyCredential.isUserVerifyingPlatformAuthenticatorAvailable());
  } catch {
    return false;
  }

/** Gọi NGAY trong lần chạm (không await fetch trước đó) — iPhone có thể chặn nếu không (đặc tả §2.7). */
export async function getAssertion(o: Api.PasskeyRequestOptionsResponse["publicKey"]): Promise<Api.PasskeyCredentialJson> {
  const cred = (await navigator.credentials.get({
    publicKey: { challenge: buf(o.challenge), rpId: o.rpId, timeout: o.timeout, userVerification: o.userVerification, allowCredentials: o.allowCredentials.map((c) => ({ type: c.type, id: buf(c.id) })) },
  })) as PublicKeyCredential;
  const r = cred.response as AuthenticatorAssertionResponse;
  return {
    id: cred.id,
    rawId: b64(cred.rawId)!,
    type: "public-key",
    response: { clientDataJSON: b64(r.clientDataJSON)!, authenticatorData: b64(r.authenticatorData)!, signature: b64(r.signature)!, userHandle: b64(r.userHandle) },
  };
}

export async function createCredential(o: Api.PasskeyCreationOptionsResponse["publicKey"]): Promise<Api.PasskeyCredentialJson> {
  const cred = (await navigator.credentials.create({
    publicKey: {
      challenge: buf(o.challenge),
      rp: o.rp,
      user: { id: buf(o.user.id), name: o.user.name, displayName: o.user.displayName },
      pubKeyCredParams: o.pubKeyCredParams,
      timeout: o.timeout,
      attestation: o.attestation,
      authenticatorSelection: o.authenticatorSelection,
      excludeCredentials: o.excludeCredentials.map((c) => ({ type: c.type, id: buf(c.id) })),
    },
  })) as PublicKeyCredential;
  const r = cred.response as AuthenticatorAttestationResponse;
  return { id: cred.id, rawId: b64(cred.rawId)!, type: "public-key", response: { clientDataJSON: b64(r.clientDataJSON)!, attestationObject: b64(r.attestationObject)! } };
}
```
