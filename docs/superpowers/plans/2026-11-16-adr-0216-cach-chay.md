# ADR-0216 — Cách chạy (xoá ảnh khỏi lịch sử kho)

Hồ sơ có ngày 2026-11-16. Quyết định: `docs/adr/ADR-0216-xoa-anh-khoi-lich-su-kho.md` (accepted 16/11). Tệp này chỉ nói **gõ gì, theo thứ tự nào**.

## Điểm khác so với chữ của ADR (làm chặt hơn, không nới)
- Bước 3 lọc trên **bản sao mới của kho trên máy** (không phải bản tải từ GitHub), nên **mọi nhánh trên máy** — kể cả nhánh chưa gộp — đều được lọc theo. Vì vậy bước 2 không cần gộp nhánh: chỉ cần **không còn phần sửa chưa lưu và không còn bản làm việc riêng**. Nhánh nào chủ muốn bỏ thì vẫn bỏ được, nhưng không bắt buộc.
- Bốn nhánh chỉ có trên GitHub, chưa gộp (`claude/clever-hertz-0f1b61`, `claude/kiem-doc-lap-khung-gd`, `worktree-xac-nhan-don`, `worktree-xac-nhan-don-2`) đã được chép thành nhánh trên máy (16/11) để không mất khi xoá nhánh trên GitHub.
- Phạm vi đúng ADR: ảnh `.png`/`.jpg` dưới `docs/evidence/`. Ảnh tham chiếu dưới `docs/design/` **giữ nguyên**.
- ADR bước 1 nói sao lưu «ra ổ ngoài». Máy hiện không có ổ ngoài: mặc định `~/Backup/` (cùng ổ). Có ổ ngoài thì dùng `--thu-muc` trỏ sang ổ đó — đây là chỗ duy nhất lỏng hơn chữ ADR.

## Bước 0 — trước ngày chạy
1. `scripts/chuan-bi-0216.mjs` phải có trên `main` (đi cùng lần `day-len` của nhánh `claude/kiem-nhanh-a-b`).
2. Chủ cài công cụ lọc, một lần:
   ```bash
   brew install git-filter-repo
   ```

## Bước 1–3 — máy làm, không đụng GitHub hay kho đang dùng
3. Cho xong hoặc dừng mọi phiên Claude của tourdao-sales; phần sửa chưa lưu thì lưu (commit) hoặc chủ quyết bỏ; **lưu trữ** (archive) các phiên đó để ứng dụng gỡ bản làm việc riêng. Bản làm việc nào còn sót: `git worktree remove <đường dẫn>` (không `--force`; nhánh vẫn giữ).
4. Ở thư mục gốc kho, kiểm điều kiện (chỉ đọc):
   ```bash
   cd /Users/tuanbao/Documents/Projects/ctytnhhtourdao/tourdao-sales && node scripts/chuan-bi-0216.mjs --kiem
   ```
   Mọi dòng phải **ĐẠT**. Dòng CHƯA có in sẵn cách sửa.
5. Chạy chuẩn bị (sao lưu → lọc trên bản sao mới → đối chiếu). Mặc định để ở `~/Backup/tourdao-truoc-0216-<ngày>/`; có ổ ngoài thì thêm `--thu-muc /Volumes/<ổ>/tourdao-truoc-0216`:
   ```bash
   cd /Users/tuanbao/Documents/Projects/ctytnhhtourdao/tourdao-sales && node scripts/chuan-bi-0216.mjs
   ```
   Lệnh tự dừng nếu: bản sao lưu lệch nhánh, còn ảnh sau khi lọc (kể cả ảnh tên tiếng Việt), có nhánh nào khác nội dung ngoài ảnh, hoặc nội dung `main` hiện tại đổi dù một byte. Xong thì in **hai khối lệnh A và B** cho Bước 4 và 6, đã điền sẵn đường dẫn. Tệp chưa theo dõi ở checkout chính (`.dev.vars`, `node_modules`…) không bị đụng.

## Bước 4–6 — PHẦN MỘT CHIỀU, chủ tự gõ trong ứng dụng Terminal
Không dùng `!` trong phiên AI (hàng rào chặn AI đẩy cưỡng bức là đúng, không tắt). Dán đúng hai khối mà lệnh ở mục 5 in ra, theo thứ tự. Mỗi khối mở đầu bằng **chốt chặn** (`--soat`): nếu từ lúc sao lưu có lần lưu mới, nhánh mới, bản làm việc mới, hay `main` trên GitHub đã đổi, khối dừng ngay, chưa làm gì; các lệnh nối bằng `&&` nên một lệnh hỏng là dừng cả khối.
- **Khối A (Bước 4).** Đẩy `main` đã lọc lên GitHub (chỉ đè khi `main` trên GitHub còn đúng bản lúc sao lưu), rồi xoá mọi nhánh trên GitHub trừ `main` (khoảng 90 nhánh `cho-kiem/*` + 5 nhánh cũ; bản đã lọc của các nhánh chưa gộp vẫn nằm trên máy).
- **Khối B (Bước 6).** Đưa kho đang dùng sang lịch sử mới: lấy mọi nhánh đã lọc, đặt lại `main`, dọn lịch sử cũ. Dòng kiểm sau cùng phải ra `0`.

Sau đó lần `day-len` kế tiếp (việc bình thường) tạo bản ghi kết luận kiểm theo mã mới; `trien-khai` cần bản ghi đó.

## Bước 5 — nhờ GitHub dọn bản lưu của 19 PR
GitHub giữ riêng lịch sử mỗi PR (`refs/pull/1..19/head`); chủ kho không xoá được. Gửi tại https://support.github.com/contact (mục «Removing sensitive data»), nội dung gợi ý:

> Repository luutuanvu1010/tourdaobooking. I rewrote history with git-filter-repo to remove all files under `docs/evidence/` with extensions .png/.jpg, force-pushed `main`, and deleted every other branch. Please remove cached views and dereference the old commits held by pull requests #1–#19 (refs/pull/*/head) and run garbage collection, so the removed images are no longer reachable.

GitHub không nhận dọn thì ảnh vẫn lấy được qua 19 PR; sạch hẳn chỉ còn cách kho mới (quyết định khác, ADR-0216 «Hệ quả»).
